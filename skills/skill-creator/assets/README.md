# Skill Template Assets

# This directory contains example assets for skill creation

## Template Examples

### Document Templates

- `report_template.docx` - Standard report format
- `presentation_template.pptx` - Slide deck template

### Code Templates

- `python_boilerplate.py` - Basic Python script structure
- `react_boilerplate/` - React component starter

### Style Assets

- `logo.png` - Example logo
- `brand_guidelines.pdf` - Brand documentation

## Usage Notes

Assets are files that get used in the final output but are not loaded into the AI context. They're copied, modified, or referenced during skill execution.
