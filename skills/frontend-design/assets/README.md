## Customization Tips

### Color Schemes

Edit CSS variables in each template:

```css
:root {
  --primary-color: #your-color;
  --secondary-color: #your-accent;
}
```

### Typography

Replace Google Fonts imports:

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Your+Font&display=swap" />
```

### Animations

Adjust timing functions and durations:

```css
animation: fadeInUp 1s ease-out 0.2s forwards;
```
